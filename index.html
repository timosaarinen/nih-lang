THE SMALL PRINT
Every pixel starts here.
fn pixel(uv: vec2, t: f32) -> vec4 {
  vec4(uv, 0.5 + 0.5 * sin(t), 1.0);
}
uv runs from 0 to 1, left to right and top to bottom. t is time in seconds. Return red, green, blue, alpha values from 0 to 1.
Use immutable locals, f32, vec2/3/4, helper functions, arithmetic, swizzles, and numeric builtins such as sin, cos, sqrt, length, dot, min, max and lerp. This first canvas compiler accepts straight-line numerical code. Unsupported constructs produce an error.
Live mode compiles after a short typing pause. A failed edit keeps the last working canvas. Pause stops the worker; Resume recreates it. Your draft is saved in this browser when storage is available.
