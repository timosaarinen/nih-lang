# Product Requirements Document (PRD)

## NIH Language

### 1. Introduction

**NIH** is a new, KISS-oriented programming language designed for AI-centric literate programming. It combines simple, Lua-style block syntax with explicit hash directives for file and cell boundaries, making code both human-readable and trivially parseable by AI models and tools.

### 2. Objectives
- **Human-first**: Minimize visual noise and leverage familiar constructs (`fun...end`, `while...end`, etc.).  
- **AI-first**: Provide unambiguous structure for large language models (LLMs) via clear directives and minimal grammar.  
- **Literate by default**: Integrate documentation (Markdown) and code in a single stream with explicit boundaries.  
- **Multi-file support**: Bundle and extract multiple source files in one document.

### 3. Key Features

1. **Hash Directives**  
   - `#file name="..." lang="nih-block"` starts a file; content defaults to Markdown until a `#code` block.  
   - `#code` / `#end code` wrap code sections.  
   - Omit `#markdown` directives: everything outside `#code` blocks is Markdown.  
   - `#end file` ends the file section.

2. **Lua-style Block Syntax**  
   - Function: `fun name(args): RetType ... end`  
   - Conditionals: `if cond then ... end`  
   - Loops: `while ... do ... end`, `for var = start, stop do ... end`

3. **Literate by Default**  
   - Markdown is the base mode; code sections are explicitly marked.  
   - Simplifies authoring and parsing: two modes only (Markdown vs Code).

4. **Metadata Attributes**  
   - File name and language in `#file` directive.  
   - Optional attributes (e.g. `description`) can be added later.

5. **AI Tooling**  
   - Trivial two-state parser (Markdown until `#code`).  
   - Compatible with LSP, canonical formatter, semantic embeddings.

---

### 4. Workflow Scenarios

- **Single-file script**: Use a single `#file` block; omit `name` for a default script file.  
- **Multi-file project**: Chain multiple `#file` blocks; extract via tooling.  
- **IDE integration**: Syntax highlighting, collapsible code regions, Markdown rendering by default.

### 5. Full Mandelbrot Example

In this example, Markdown is the default. We only mark code sections explicitly.

```nih
#file name="src/mandelbrot.nih" lang="nih-block"

# Mandelbrot Set Visualization

Compute the escape count for each point and render ASCII art.

#code
fun mandelbrot(cx: Float, cy: Float): Int
  maxiters = 80
  zx = 0.0; zy = 0.0; n = 0

  while n < maxiters do
    px = zx*zx - zy*zy
    py = 2 * zx * zy
    zx = px + cx
    zy = py + cy

    if sqrt(zx*zx + zy*zy) > 2 then
      return 0    // escaped immediately
    end

    n += 1
  end

  return n
end
#end code

## Setup & Render Loop

Define grid dimensions and bounds, then draw the set row by row.

#code
WIDTH  = 40; HEIGHT = 20
rs = -2.0; re = 1.0
is = -1.0; ie = 1.0

for j = 0, HEIGHT - 1 do
  for i = 0, WIDTH - 1 do
    cx = rs + (i / (WIDTH - 1)) * (re - rs)
    cy = is + (j / (HEIGHT - 1)) * (ie - is)
    m  = mandelbrot(cx, cy)
    printchars(m > 0 ? '*' : ' ')
  end
  printlf()
end
#end code

#end file
```
